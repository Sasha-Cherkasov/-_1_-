Простое консольное приложение для управления складом товаров.

 Функционал
- Добавление товаров (название, количество, цена)
- Операции restock (пополнение) и sell (продажа)
- Автоматический расчет общей стоимости товаров
- Сортированный вывод результатов

 Используемые технологии
- Go (стандартная библиотека)
- Структуры данных (struct, map, slices)
- Сортировка результатов
